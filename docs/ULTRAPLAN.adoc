=== 1.3 Mathematical Foundations — Why This Is World-Changing (Your Note)

Per `docs/academic/mathematical-foundations/`:

* **Categorical semantics**: LCCC for dependent types (Π/Σ as adjoints Σ⊣τ*⊣Π), SMCC for linear/affine (⊗, ⊸), graded comonads D_π for QTT (D_0≈I erased, D_1≈Id linear, D_ω=! exponential), Freyd categories for effects, fibrations for refinements, presheaf over regions for borrow.
* **Logic foundations**: Curry-Howard extended: affine = affine logic (weakening allowed, contraction controlled via ω), QTT = graded linear logic, effects = modal/◇, ownership = reader/state comonads.
* **Totality cut**: L1 equality = normalize-and-compare, no coercion proofs. Type-level language total by construction (no recursion constructor, %default total). This is the anti-System-Fc move. Haskell's System Fc carries coercion machinery inside equality — the thing this design refuses.
* **Grade algebra**: semiring (0,1,ω, +, ×, ≤) with laws as proof fields in Anytype.Grade.Algebra. Instances: affine {0,1,ω}, exact-usage ℕ, privacy budget, security lattice Low≤High, probability [0,1], Latency×Billing. Same kernel, distinct disciplines — demonstrated in anytype golden matrix.
* **Coherence cliff**: v0.1 hit failure where equality machinery collapses under own weight. Forked to Panoply (austere lab) + Anytype/SystemET (rebuilt foundation). v0.2 = "save faces" on kernel built to carry them.
* **Borrow checker**: lexical + NLL last-use expiry + flow-sensitive escape via re-assignment + CFG-join merge_arm_results + loop 2-iteration re-check + @linear capture rejection + Polonius M1-M3 test-only extractor with datalog-style loan-live-at-point solver (ADR-022, #553, 7 known divergences).
* **Proof status**: per SOUNDNESS.adoc: #554 fixed (callee-returned borrow UAM), #555 loud-fail (handle/resume on compiled backends + multi-shot), residual pinned #555 non-tail single-shot (#623), #556 loud-fail (async CPS table-miss), #558 removed (refinement), #559 fixed (trait coherence), #553 partial (Polonius), etc. Coq/Rocq codegen preservation initial, Idris2 Solo-core QTT metatheory, Lean tropical-session-types, Agda echo-boundary.

**World-changing claim**: If L2 pluggable grades + L1 totality cut holds, you get a **dial-a-discipline kernel** that can produce privacy-typed queries, security-typed, cost-visible edge functions, affine-safe game mods, without rebuilding a language each time. AffineScript is just dial setting `affine+cost`. That is the bet.
